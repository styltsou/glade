# Changelog

## Unreleased

### Find and organize notes

- Open the Links drawer to see both the notes that link to the current note and the notes it links to. Resize the drawer or the table of contents as you work.
- Choose whether Glade shows note titles or full file names in the sidebar, tabs, breadcrumbs, and Home.
- Open the note’s actions from the last breadcrumb. Rename, duplicate, pin, reveal the note in your file manager, or copy its path from the menu.
- Open a different folder or file in the current window. Open Recent now uses the same layout as the command palette.

### Edit notes

- Drag table rows and columns with a visible preview, a clear drop marker, and intact borders around the original slot. Dragging no longer expands the table’s scroll area.
- Copy, duplicate, or delete a block from its grip menu. The text selection toolbar now names its actions with tooltips.
- Choose a code block’s language from a list by typing its name or alias. Copy code directly from the block, and switch Mermaid diagrams between the rendered diagram and highlighted source.
- Use mouse hover or arrow keys to pick items in block and mention menus. The command palette ranks matches against the text shown in the list.

### Polish and fixes

- Expand the floating sidebar into the docked sidebar without a jump in height. Empty folders show a clear empty state.
- Nested bullet markers vary with indentation depth. Tag lists show how many tags are hidden when space runs out.
- Editing a title keeps accent marks visible, and saving a note keeps the editor in place.
